# سجل الورديات — مشروع APK آمن

## الخطوات
1. افتح `tools/license-tool.html` في متصفح الكمبيوتر ← "إنشاء مفاتيح جديدة" ← انسخ المفتاح العام والصقه في `www/index.html` مكان `const PUB=null` (يصبح `const PUB={...}`). احفظ نسخة من المفتاح الخاص في مكان آمن.
2. أنشئ مستودعًا خاصًا (Private) على GitHub وارفع كل محتويات هذا المجلد (بما فيها `.github`).
3. من تبويب Actions شغّل **Build APK**، وبعد انتهائه نزّل `nursing-apk` من أسفل الصفحة وثبّته.
4. عند أول فتح: انسخ رمز الجهاز ← وقّعه في أداة الترخيص ← الصق الرقم التسلسلي ← أنشئ كلمة مرور.

## توقيع الإصدار (اختياري، موصى به)
أنشئ مفتاح توقيع مرة واحدة: `keytool -genkey -v -keystore ks.jks -alias nurse -keyalg RSA -keysize 2048 -validity 10000`
ثم أضف في Settings ← Secrets ← Actions: `KS_B64` (نتيجة `base64 -w0 ks.jks`) و`KS_PASS` و`KS_ALIAS` و`KEY_PASS`. بدونها يُبنى إصدار تجريبي (debug) أقل أمانًا.

## الشعار
ضع صورة 1024×1024 باسم `resources/icon.png` (أيقونة ممرضة جاهزة، ويمكن استبدالها).
